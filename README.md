# GenAI Career Navigator 🚀

## 📌 About the Project
GenAI Career Navigator is a web-based application designed to help students explore suitable career paths based on their skills, interests, and goals. It aims to make career planning easier through personalized guidance.

## 🎯 Objectives
- Help students explore potential career roles.
- Analyze skills and interests.
- Provide career recommendations.
- Support students in planning their learning journey.

## 🛠️ Technologies Used
- **Frontend:** React, JavaScript, HTML, CSS
- **Backend:** Python, FastAPI
- **Data Format:** JSON
- **Tools:** Git, GitHub, VS Code

## ✨ Key Features
- Career role exploration
- Skill analysis
- Career recommendations
- AI-powered career guidance
- Interactive dashboard

## 🏗️ Project Structure
- `backend/` – Backend API and application logic
- `frontend/` – User interface and frontend components
- `data/` – Project data files
- `requirements.txt` – Python dependencies

## ⚙️ How to Run
1. Clone or download this repository.
2. Install the required Python dependencies:
   `pip install -r requirements.txt`
3. Start the backend using the instructions in the backend files.
4. Start the frontend using the instructions in the frontend files.

**Note:** Exact commands may depend on the project's configuration.

## 🎓 Project Purpose
This project demonstrates the use of frontend development, Python APIs, and AI-based career guidance to help students make informed career decisions.
